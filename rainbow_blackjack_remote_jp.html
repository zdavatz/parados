レインボー・ブラックジャック — ルール

概要

2人のプレイヤーが一緒に6色のタワーを積み上げます。目標：各タワーの合計をできるだけ21に近づけること。タワーに最後の石を置いたプレイヤーが、そのタワーの得点を獲得します。

用具

  • 色付きの石36個：赤・青・黄・緑・オレンジ・紫それぞれ1〜6
  • 灰色のジョーカー石6個（プレイヤーごとに3個）
  • プレイヤー1：原色（赤・青・黄）＋ジョーカー3個 = 21個の石
  • プレイヤー2：二次色（緑・オレンジ・紫）＋ジョーカー3個 = 21個の石

ゲームの準備

  • プログラムが各プレイヤーからランダムに3個の石を取り除きます。これらはゲームには使われません。
  • 最初の9個の石はプログラムによってランダムに3×3のマス目に配置されます — 相手には見えません！
  • 自分の石を見て、位置を覚えておくことができます。

色相環と隣り合わせ

6色は環を形成します：赤 — オレンジ — 黄 — 緑 — 青 — 紫（そして赤に戻る）。
各石は、自分の色のタワーまたは両隣のタワーに置くことができます：

  • 🔴 赤 → 紫・赤・オレンジのタワー
  • 🟠 オレンジ → 赤・オレンジ・黄のタワー
  • 🟡 黄 → オレンジ・黄・緑のタワー
  • 🟢 緑 → 黄・緑・青のタワー
  • 🔵 青 → 緑・青・紫のタワー
  • 🟣 紫 → 青・紫・赤のタワー

ゲームの進行

  • 各ラウンドは3手で構成されます。
  • ラウンドの開始時に、各プレイヤーは自分のマス目から任意の方向の1列（石3個）を取り、その3個の石の色または数字のいずれかを宣言します（灰＝0）。
  • その後、プレイヤーは交互に1個ずつ石をタワーに置きます（1ラウンドにつき3手）。
  • 各色付きの石は、自分の色のタワーか、色相環上の両隣のタワーに置けます。灰色のジョーカーはどのタワーにも置けます。

マス目とラウンド

  • ラウンド1〜3：最初の3×3のマス目の石を使用。最初の列は任意の方向で自由に選べ、その後は残り2列のいずれか。
  • ラウンド4〜6：残りの9個の石がプログラムによって新しい3×3のマス目に配置されます。最初の列は任意の方向で自由に選べ、その後は残り2列のいずれか。
  • 一度選んだ方向は、同じマス目のその後すべてのラウンドに適用されます。

手番の順序

ラウンド1：プレイヤー1が先攻、ラウンド2：プレイヤー2、ラウンド3：プレイヤー1、ラウンド4：プレイヤー1、ラウンド5：プレイヤー2、ラウンド6：プレイヤー1。そのラウンドの先攻者が最初に自分の列を選び、各手番で最初に石を置きます。

灰色のジョーカー

  • ジョーカーは、そのタワーに最後に置かれた石の値を引き継ぎます。
  • ジョーカーはタワーの最初の石として置くことはできません。
  • ジョーカーを2個連続して置くことはできません。
  • ジョーカーの置き換え：ジョーカーが一番上にあり、21により近づく色付きの石を持っているが、ジョーカーのままだと21を超えてしまう場合、ジョーカーを取り除いて自分の石を置くことができます。

得点

各タワーには色付きの点（赤＝プレイヤー1、緑＝プレイヤー2）が表示され、誰が最後の石を置いたかを示します。

  • 即勝ち：ちょうど21に達したタワーを3つ最初に所有したプレイヤーが即座に勝利します！
  • 21のタワーを3つに達したプレイヤーがいない場合、最終的により多くのタワーを所有したプレイヤーが勝ちます。
